# Pygame Bouncing Football

A lightweight 2D Python animation built with Pygame featuring a spinning football that moves and bounces off the boundaries of a grass field.

## Requirements
* Python 3.x
* Pygame (`pip install pygame`)

## How to Run
1. Clone this repository or download the files.
2. Make sure `background.png` and `football.png` are in the same directory as `football_game.py`.
3. Run the script:
   ```bash
   python football_game.py
   ```
